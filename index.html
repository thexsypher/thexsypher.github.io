System Architecture — Production Design

Engineered for sub-100ms reads and zero-cost idle compute.

Every architectural subsystem below is extracted directly from lib/, app/, and docker-compose.prod.yml in the production repository.

Data & Blob LayerHybrid PostgreSQL + Cloudflare R2

Relational metadata (title, slug, deck, status, categoryId, previousSlugs, views) lives in PostgreSQL via Drizzle ORM, while heavy compiled HTML & TipTap JSON payloads live in Cloudflare R2 linked via Article.contentUrl (lib/storage.ts).

Drizzle ORM 0.45Cloudflare R2PgBouncer 6432

Caching & PerformanceTagged ISR & Sub-Millisecond Search

Listing queries use Next.js unstable_cache with granular cache tags (articles, article:{slug}, category:{slug}). Live search ranks an in-memory snapshot, delivering sub-millisecond query latency across the entire catalog without database wakeups.

unstable_cacheTag RevalidationIn-Memory Ranker

Rich Editorial SuiteTipTap 3 + AST Schema Synthesis

Custom TipTap 3 extensions (Mermaid 12 diagrams, Recharts interactive charts, SpecSheets, Pros/Cons, ScoreBreakdowns, Lowlight code blocks) sanitized via DOMPurify (lib/sanitize.ts) and parsed into dynamic TechArticle, FAQPage, HowTo & SoftwareSourceCode JSON-LD (lib/article-schema.ts).

TipTap 3.31DOMPurifyMermaid 12

Async Job PipelineBullMQ + Redis AOF Workers

Dedicated xsypher-worker container processes BullMQ queues over AOF-persisted Redis (volatile-lru): scheduled article publication, Resend transactional & newsletter broadcasts, view-counter flushes, and automated Google Indexing API pings (lib/google-indexing.ts).

BullMQ 6.3IORedis 6.0Google Indexing API

Security & IdentityNextAuth v5 + Capability RBAC + 2FA

Role-Based Access Control enforced exclusively through authorize(role, capability) and buildArticleScope(actor) in lib/capabilities.ts. TOTP 2FA secrets encrypted at rest (lib/totp.ts), per-request CSP nonces in middleware.ts, and subdomain isolation for admin.xsypher.com.

NextAuth v5TOTP 2FACSP Nonces

Technical SEO & CrawlEdge 410 Tombstones & Image Hygiene

Deleted slugs return instant HTTP 410 Gone at the edge via lib/deleted-slugs.ts + /api/deleted-slugs. lib/stale-assets.ts blocks placeholder art from metadata, while lib/image-url.ts serves width-capped AVIF/WebP via Cloudflare /cdn-cgi/image/ transforms.

HTTP 410 GoneNews SitemapAVIF / WebP
